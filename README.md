# Life OS

Aplicação pessoal baseada no visual de `Templates/Figma`, mantido sem alterações.

## Executar

```bash
npm install
npm run dev
```

O build de produção é gerado com `npm run build`.

## Dados

Os registros são persistidos no `localStorage` do navegador. Em **Configurações → Dados** é possível exportar/importar um backup JSON ou restaurar os dados de demonstração.
